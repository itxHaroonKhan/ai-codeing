# HealthFlow AI - Comprehensive Clinic Management SaaS

**HealthFlow AI** is a professional-grade, AI-powered SaaS platform designed for modern medical clinics to streamline operations and enhance patient care through intelligent diagnostics.

## 🚀 Key Features

- **Multi-Role Dashboards**: Specialized portals for Admins, Doctors, Receptionists, and Patients.
- **Smart AI Diagnosis**: GenAI-driven symptom analysis to assist medical professionals in identifying potential conditions.
- **Clinical Risk Flagging**: Automated scanning of medical history to identify chronic patterns or dangerous health combinations.
- **AI Prescription Explainer**: Translates complex medical prescriptions into easy-to-understand guides and lifestyle advice for patients.
- **EHR Timeline**: A comprehensive, real-time medical history for every patient stored in Firestore.
- **Lab Analysis**: Intelligent extraction of key findings and critical flags from medical PDF reports.

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS & ShadCN UI
- **AI Engine**: Google Genkit with Gemini 2.5 Flash
- **Database**: Firebase Firestore
- **Authentication**: Firebase Auth (Role-based)

## 📦 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/itxHaroonKhan/ai-codeing.git
   cd ai-codeing
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Environment Variables**:
   Create a `.env` file and add your `GEMINI_API_KEY`.

4. **Run Development Server**:
   ```bash
   npm run dev
   ```
